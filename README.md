# Scryify

> **Note: Scryify is a fictitious company.** This site is used internally by Revelica as a test target — a realistic-looking SaaS marketing site for validating product research workflows.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- shadcn/ui components
- React Router

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
